# 01_Porfolio — Web de Porfolio Personal Estática

Proyecto desarrollado para la **Tarea 1: Porfolio** dentro de la práctica **Desarrollo con Vibe Coding** (EASD / ESI Valladolid, Curso 2026/2027).

---

## 📌 Descripción del Proyecto
Este proyecto consiste en el diseño y desarrollo de una web de porfolio personal estática utilizando metodologías de **Vibe Coding** y modelos de Inteligencia Artificial. El flujo de trabajo partió de la selección e inspección de una web de referencia existente, la generación del código base mediante prompts guiados y una posterior fase de iteración y personalización en GitHub para transformarlo en una pieza con identidad visual propia que deja atrás la copia inicial.

---

## 📁 Estructura del Repositorio
La carpeta `01_Porfolio` está estructurada de forma limpia para facilitar su inspección y despliegue directo:
